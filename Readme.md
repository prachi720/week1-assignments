## Project Objective
This repository contains all three Week 1 frontend development tasks completed for the WeIntern Web Development Internship. The goal of these projects is to demonstrate clean semantic HTML5 structure, modern responsive CSS3 layouts (Flexbox and CSS Grid), smooth animations, and organized project delivery.

---

## Projects Included

### 1. Personal Portfolio Website (`Portfolio-website/`)
* A 4-page responsive developer portfolio featuring **Home**, **About**, **Projects**, and **Contact** pages.
* Built with consistent navigation, reusable CSS variables, a clean card-based grid, and a styled contact form.

### 2. Responsive Business Landing Page (`Business-landing page/`)
* A single-page restaurant website for **The Savory Bistro**.
* Includes a sticky navigation bar, hero section with call-to-action buttons, a 4-card signature offerings grid, and a table reservation form with HTML5 validation.

### 3. CSS Layout & Animation Challenge (`CSS-Challenge/`)
* A responsive layout playground demonstrating:
  * **Flexbox Row:** 3 equal-width cards on desktop that stack vertically on mobile devices.
  * **CSS Grid Matrix:** A 6-item responsive dashboard grid using `repeat()` and `auto-fit`.
  * **CSS Animations:** Smooth button hover transitions and a keyframe-powered circular loading spinner.

---

## Tech Stack
* **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) and form validation.
* **CSS3:** Flexbox, CSS Grid, Custom Properties (`:root`), Media Queries (`< 768px`), and `@keyframes` animations.
* **Deployment & Version Control:** Git, GitHub, and Vercel.
